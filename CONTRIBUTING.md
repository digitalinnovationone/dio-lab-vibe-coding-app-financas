# Contributing to ChatMoney

Obrigado pelo interesse em contribuir com o ChatMoney! Siga estas diretrizes para facilitar a colaboração.

- Abra uma issue antes de trabalhar em mudanças significativas — descreva o problema ou a proposta.
- Crie um branch com nome descritivo: `feature/nome-curto` ou `fix/descricao-curta`.
- Faça commits pequenos e com mensagens claras (imperativo, em inglês ou português).
- Garanta que alterações na documentação estejam no mesmo PR.
- Inclua exemplos ou capturas quando relevante.

Processo de revisão
- O mantenedor revisará seu PR; seja paciente e responda aos comentários.
- PRs sem descrição clara podem ser fechados até que haja informação suficiente.

Estilo de código
- Siga a padronização do projeto quando existir (eslint, prettier, etc.).
- Se não houver padrão definido, mantenha o código legível e com comentários quando necessário.

Referências
- Veja também os templates de Issue e Pull Request em `.github/`.

Obrigado! 👏
