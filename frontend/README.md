# Frontend

This folder should contain the client app (web or mobile) for ChatMoney. It is intentionally empty in the scaffold; add your preferred stack:

Suggestions:
- Web: Next.js (React) with pages/app router, call backend at /api or directly to backend server.
- Mobile: Flutter or React Native.

Example quick-start (if using Next.js):
1. cd frontend/web
2. npx create-next-app@latest .
3. Add a simple chat UI that POSTs messages to backend at `http://localhost:3001/chat`.

Keep UI accessible and follow the Design Universal guidelines in docs/PRD.md.
